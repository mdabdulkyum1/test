# Winter Clothing Donation

A web application to facilitate the donation of winter clothing, ensuring that help reaches those in need during the colder months. This platform connects donors with donation drives or individuals in need.

## Project Overview
The **Winter Clothing Donation** platform aims to create an efficient and seamless process for donating winter clothing. By leveraging modern web technologies, the project ensures accessibility, scalability, and user-friendliness for donors and organizers alike.

---

## Key Features
- **User Authentication**: Secure login and registration using Firebase.
- **Responsive Design**: Fully responsive interface for a seamless experience on all devices.
- **Donation Management**: Manage donation items, view drives, and track contributions.
- **Interactive UI**: Smooth animations and a user-friendly interface using Swiper and React Icons.
- **Notifications**: Real-time notifications using React Toastify and SweetAlert2.
- **SEO Optimization**: Dynamic page titles and meta descriptions with `react-helmet-async`.

## npm Packages
The following npm packages are utilized in this project for various functionalities:
- **Firebase**: `^11.0.2` - Authentication and database management.
- **LocalForage**: `^1.10.0` - Local storage management for offline support.
- **Match Sorter**: `^8.0.0` - Simplified sorting and filtering.
- **Prop Types**: `^15.8.1` - Runtime type checking for React props.
- **React**: `^18.3.1` - Library for building user interfaces.
- **React DOM**: `^18.3.1` - React's package for DOM rendering.
- **React Helmet Async**: `^2.0.5` - Dynamic meta tags and SEO management.
- **React Icons**: `^5.3.0` - A comprehensive set of icons for React applications.
- **React Router DOM**: `^6.28.0` - Routing and navigation for the app.
- **React Toastify**: `^10.0.6` - Toast notifications for user feedback.
- **Sort By**: `^1.2.0` - Simple utility for sorting data.
- **SweetAlert2**: `^11.14.5` - Modern alerts, popups, and dialogs.
- **Swiper**: `^11.1.14` - Modern sliders and carousels for an interactive UI.
